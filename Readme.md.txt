# 🍽️ SmartStock: Интеллектуальная система управления складом и стоп-листами для HoReCa

Проект разработан для хакатона (Кейс 3: Мониторинг остатков, сроков годности и стоп-листов).

---

## 🚀 О проекте
Рестораны ежедневно теряют деньги из-за списания просроченных продуктов и ручного контроля остатков. **SmartStock** — это автоматизированная B2B-система, которая решает эту проблему на уровне склада, кухни и зала ресторана.

### 🔥 Ключевые фичи:
1. **Партионной учет (FIFO):** Учет продуктов по партиям поставок. Система автоматически списывает ингредиенты по принципу "первым пришел — первым истекает срок годности".
2. **Динамический стоп-лист:** Блюда автоматически блокируются в реальном времени, если для них на складе не хватает хотя бы одного ингредиента.
3. **Рекомендательный движок («Горячие предложения»):** ML-алгоритм рассчитывает приоритет продажи блюд на основе остаточного срока годности продуктов, стимулируя продавать то, что скоро испортится.
4. **Дашборд и аналитика:** Контроль списаний, статистика дефицитных ингредиентов и алерты о критических сроках годности.
